# Infollion Log Analysis Assignment

This repository contains my solution for the production log analysis
assignment.

## Files

- `Investigation.md` - Investigation approach and reasoning
- `ANSWERS.md` - Final findings and answers
- `analyze.py` - Python script used for log analysis
- `web.log` - Web server logs
- `worker.log` - Worker logs
- `Log_Reading_Assignment_v2.pdf` - Assignment document

## Analysis

The investigation correlates web requests and worker failures using
request_id and analyzes checkout failures, error patterns, affected
users, and possible areas for further investigation.
